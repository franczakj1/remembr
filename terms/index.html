Program

Remembr is a personal household-assistant text messaging program operated by Jason (sole proprietor). Users text details about their home to save them, text questions to get them back, and receive reminder texts when household tasks are due.

Opting in

You join by texting +1 630-491-0184 first (for example START or any household detail). We never add anyone who has not texted us first.

Message frequency and cost

Message frequency varies with how you use the service and how many reminders you set. Message and data rates may apply.

Cancel

Text STOP (or UNSUBSCRIBE, CANCEL, END, QUIT, STOPALL) at any time to cancel. You will get one confirmation message and no further messages. Text START to rejoin.

Help

Text HELP (or INFO) for help, or email jasonfranczak@yahoo.com.
